# Pinned Unicode data

`unicode-bounds.bin` contains 20,937 non-identity expansion-bound entries generated by enumerating all Unicode scalars with ICU4J 78.1 / Unicode 17. Runtime reads verify the fixed SHA-256 and validate structure before use.

`profiles.json` records the exact pipeline, data checksums and policies for `unicode_search_v1`. Its fingerprint hashes the sorted compact JSON profile object excluding `fingerprint_sha256`. Package audits verify the pinned ICU JAR and require exactly the declared resource inventory.

See [offline generation](../tools/README.md). A change to successful normalization output requires a new profile ID.
